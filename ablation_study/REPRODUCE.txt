Run in a NEW execution directory. Original models and the public GanExpansion
checkout must remain unchanged. All outputs use ablation_results/ or
ablation_recreated/. The queue never retunes a failed model.

FULL STUDY

First record the existing full TwoRoom reference's exact training RNG stream:

  python -m ablation_study.launch --name train_tworoom_base_full_s42 -- \
    python -u -m ablation_study.run_original --module tworoom_gan.train \
    --config ablation_study/configs/tworoom_base_full_s42.json \
    --rng-trace ablation_results/rng/tworoom_base_s42.pt --rng-mode record

The queue waits for that recorded process before starting another GPU trainer:

  python -u -m ablation_study.run_queue \
    --manifest ablation_study/queue_manifest.json \

The manifest contains every exact command, dependency, configuration and expected
output file. The current runner creates a new status directory and does not
resume a previously interrupted queue automatically. Preserve its receipts and
model files; do not relaunch an old run directory blindly.

Cube evaluation uses ablation_results/calibration/CASE/best.pt and the original

adapter ablations deliberately use the published adapter recipes and their
corresponding published frozen bases. See protocol.json for the version scope.
The evaluator restores the exact frozen base and automatically loads LoRA-only
checkpoints from their ablation metadata. Ordinary inference calls:
  actor(state, base_z, private_u, skill_context, gate=1)
The original base path is gate=0. Its pretrained style modulation remains intact.
Pure LoRA-only checkpoints ignore private_u and skill_context by construction;
there is no replacement conditioner.

CHECKPOINTS AND LOGS

Exported best/latest checkpoints retain the exact inference tensors, including
the private encoder where relevant. Export manifests record both original-file
and tensor hashes. Compact exports omit optimizer and RNG state; original full
resume checkpoints remain on the execution host. RNG reference traces contain
random-number states plus batch hashes, not observation/action arrays.

For local archives, verify the announced SHA256 before using their contents:
  python3 -m ablation_study.verify_backup \
    --archive ablation_results/backups/EXPORT_NAME.tar.gz \
    --expected-sha256 ANNOUNCED_ARCHIVE_SHA256
The verifier checks every member and reuses byte-identical RNG snapshots through
hard links to verified copies. To reclaim duplicate copies in older extractions,
add --deduplicate-existing. Every path/checksum and original archive is retained;
treat extracted backups as immutable. This utility changes no experiment data.

TwoRoom base comparisons use the prespecified final step5000
(snapshots/step_005000.pt), avoiding
checkpoint ranking by an untrained encoder. Cube uses the original validation
selection rule. Adapter models use their original validation selection rules.
Do not interpret legacy placeholder-encoder diagnostics for no-latent bases.

The original base evaluator did not record checkpoint file hashes. A separate
retrospective CPU audit binds all8base comparisons to their exact selected files
by matching the first8executed commands of all37,568saved Gaussian episodes:
  python -m ablation_study.bind_base_evaluations \
    --out ablation_results/aggregate/base_evaluation_checkpoint_binding.json
Only aggregate counts/errors/checksums are exported. This does not rerun the
environment, change scores, or claim to validate later commands. The original
raw trajectories are needed on the execution host. The current evaluator
wrapper records a direct file hash for future runs as well. TwoRoom's exact
step5000snapshot files are exported and restored at the recorded CLI paths.

The initial TwoRoom ablation attempt with a posterior-noise RNG mismatch was

The final audit verifies that every removed objective is zero in the corrected

FINAL DELIVERY

After every queued job has completed and the final audit passes, export the
completed evidence with export_completed.py (repeat --previous-manifest for
earlier exports), verify its archive hash, and extract it into a fresh directory.
Use the final export's aggregate/presentation/summary.json and results/ directory
with build_report.py, plus --audit and an unused --out directory. Compile the
generated LaTeX with Tectonic or a standard LaTeX installation; inspect all pages.
The editable source and its figures must remain together.

package_delivery.py accepts --inventory, --audit, --summary, --final-export,
--report-source, --report-pdf, --smoke-proof and a fresh --out. Run with --verify-tensors using
a Python environment with Torch. It selects prior compact model exports only
when both original-source and tensor hashes match the final inventory, checks
all final-export member hashes, and creates separate weights, code, evidence and
editable-report archives plus one complete bundle. No raw GPU trajectories or
simulator arrays are included. Unzip selected_weights.zip at the execution root
to restore the canonical checkpoint paths used by the recorded evaluation CLIs.

Before packaging, verify actual loading of all56selected compact checkpoints on
the execution host, after their completed exports are available:
  python -m ablation_study.verify_compact_inference \
    --inventory ablation_results/aggregate/final_checkpoint_inventory.json \
    --exports ablation_results/exports \
    --out ablation_results/aggregate/final_compact_inference_checked.json
This compares original and compact checkpoints through the actual loaders using
fixed synthetic CPU probes: raw/EMA base actions, skill-enabled/disabled actions
and encoder outputs. Pure adapters also retain their private/context
disconnection. It is an export-fidelity check, not a new task benchmark.
Download this small JSON receipt alongside the final archive and pass it to
package_delivery.py as --smoke-proof. Packaging matches its model/source/file
hashes to every selected weight file; all56inference checks must have passed.
